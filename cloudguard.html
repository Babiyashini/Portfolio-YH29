CloudGuard Lite

A lightweight, rule-based AWS security scanner.

Python Flask AWS Boto3 Jinja2

🔍 The Problem

Manual AWS security reviews are slow and easy to miss. Small teams often deploy public S3 buckets, over-permissive IAM roles, or open security groups without realizing it.

💡 The Solution

CloudGuard Lite scans AWS configurations against a set of security rules and generates a clean HTML report with severity ratings, affected resources, and remediation recommendations.

🛡️ Rules Implemented

  • Public S3 bucket ACLs
  • S3 buckets without encryption
  • Security groups open to 0.0.0.0/0 on sensitive ports
  • IAM users without MFA
  • Over-permissive IAM policies
  • Missing CloudTrail logging

⚙️ How It Works

AWS Account (or sample JSON) → Boto3 scanners → Rule engine → Flask + Jinja2 report

📚 What I Learned

  • Writing least-privilege IAM policies for the scanner itself
  • Designing a modular rule engine (each rule = one Python function)
  • Rendering dynamic HTML reports safely with Jinja2
  • Understanding real AWS misconfiguration patterns attackers exploit

🚀 What's Next
